## 💡 文档使用建议

### 第一次使用？
1. 阅读 [../README.md](../README.md) 了解项目
2. 参考 [QUICK_TEST.md](QUICK_TEST.md) 快速测试
3. 查看 [ENV_CONFIGURATION.md](ENV_CONFIGURATION.md) 配置环境

### 理解架构？
1. 阅读 [WEBSOCKET_TUNNEL_GUIDE.md](WEBSOCKET_TUNNEL_GUIDE.md)
2. 深入 [REVERSE_PROXY_ARCHITECTURE.md](REVERSE_PROXY_ARCHITECTURE.md)

### 部署到生产？
1. 参考 [deploy-node-on-server.md](deploy-node-on-server.md)
2. 配置 [ENV_CONFIGURATION.md](ENV_CONFIGURATION.md)
3. 查阅 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

### 遇到问题？
1. 查看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)
2. 检查 [../CHANGELOG.md](../CHANGELOG.md)
3. 运行诊断脚本（在 [../scripts/](../scripts/) 目录）
